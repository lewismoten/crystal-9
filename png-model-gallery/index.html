Crystal-9 as lossless PNG byte payloads

Each image is the exact bytes of one checkpoint or deployment artifact packed into RGB channels. Alpha is fixed at 255 so a canvas can read the values without alpha premultiplication. These colors are transport data, not a visualization of learned weights.

Every card below is round-trip verified: the exported PNG was decoded by the Crystal-9 PNG decoder and checked against the source SHA-256. This page only displays the transport images; it does not yet execute model inference from canvas bytes.
